# Spark UI Slidev Talk

Slidev presentation based on sections 1, 2, and 4 of the Obsidian outline `AE/Thought leadership/Talks/Spark UI/Outline v2.md`.

## Commands

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run export`

The deck uses the `light-icons` Slidev theme and includes speaker notes in HTML comments on every slide.

Reuse the field-guide ribbon on case slides with `<DetectiveFieldGuide :active="3" compact />`, where `active` is the current investigation step (1–6).
